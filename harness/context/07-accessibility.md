# Phase 07 evidence

Screen-reader testing and a contrast audit tool were not run. Do not treat the browser checks as WCAG certification.

This session checked, in Microsoft Edge at 320px with reduced motion:

- An invalid amount is `aria-invalid` and described by the focused alert.
- Tab stays inside the record dialog, including past the dev-tools control.
- Escape closes the dialog and returns focus to “Add a manual record”.
- The close control is at least 44 by 44 pixels.
- Reduced motion sets button transition duration to `0s`.
- The dialog does not overflow horizontally.

200% zoom as a separate viewport, physical assistive technology, and automated contrast measurement are NOT RUN.

Credit-expense export rows use the report expense total. A later payable settlement is money paid out and does not add a second expense. PDF summaries now include recorded expenses and state that profit is unavailable. What-if text says it is not a guarantee and does not change saved allocations.
