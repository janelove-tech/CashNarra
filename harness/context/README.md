# Phase context

Files in this directory record material discoveries a later Cursor or Codex session would otherwise have to rediscover.

Do not copy canonical source documents into this folder. Do not duplicate `harness/CURRENT.md`, `AGENTS.md`, or `GOALS.md`. Do not paste large diffs. Do not store secrets, credentials, or customer data.

Read a context file only when the current phase file or `CURRENT.md` points to it.
